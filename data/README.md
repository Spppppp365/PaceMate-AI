# PaceMate AI

## Overview

PaceMate AI is a machine learning system designed to support daily symptom management for individuals with Postural Orthostatic Tachycardia Syndrome (POTS).

The system analyzes symptom history and daily factors to identify patterns and provide personalized symptom forecasts.

## Problem

POTS symptoms can change rapidly throughout the day. Many individuals have difficulty predicting symptom flares and planning activities.

## Goal

The goal of this project is to develop a symptom-based machine learning model that can:

- Predict symptom changes
- Identify patterns
- Support activity pacing
- Provide personalized insights

## Planned Features

- Multi-output symptom prediction
- Flare risk estimation
- Fatigue prediction
- Dizziness prediction
- Brain fog prediction
- Activity and hydration insights
