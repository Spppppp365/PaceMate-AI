# PaceMate-AI Evaluation Results

This folder contains the evaluation results for the PaceMate-AI machine-learning models.

The experiments were run using participant-level train, validation, and test splits. The evaluation covers model performance, threshold selection, longitudinal features, and robustness across repeated splits.

## Evaluation files

### `final_threshold_evaluation.csv`

Final test-set evaluation using thresholds selected from the validation set.

Includes accuracy, precision, recall, F1, ROC-AUC, PR-AUC, Brier score, confusion-matrix counts, and positive-rate statistics.

The test set was not used to select the thresholds.

### `repeated_threshold_f1_robustness.csv`

Results from five repeated participant-level splits used to examine how stable threshold selection and F1 performance are.

For each target, the file contains the validation-selected threshold along with validation F1 and test precision, recall, and F1. The summary also includes the mean, standard deviation, minimum, and maximum across repetitions.

### `longitudinal_feature_ablation.csv`

Comparison of the full feature set with a same-day-only feature set.

The full model includes historical and longitudinal measurements, while the same-day model removes those features.

The comparison includes accuracy, precision, recall, F1, ROC-AUC, PR-AUC, and Brier score.

### `repeated_longitudinal_ablation.csv`

Results from five repeated longitudinal feature ablation experiments.

Each repetition compares the full feature model against the same-day-only model for all six prediction targets.

The main comparison metrics are ROC-AUC improvement, PR-AUC improvement, and Brier score difference.

### `day9_robustness_summary.csv`

Combined summary of the repeated robustness experiments.

This file contains the average and standard deviation of the main discrimination, threshold, F1, and longitudinal-ablation results across the five repetitions.

### `robustness_statistical_analysis.csv`

Statistical analysis of the longitudinal ablation results.

For each target, this file reports the mean improvement, standard deviation, t-statistic, and p-value for ROC-AUC, PR-AUC, and Brier score difference.

## Experimental setup

The dataset contains 89,000 observations from 500 participants.

Each repeated experiment uses:

- 350 participants for training
- 75 participants for validation
- 75 participants for testing

This gives:

- 62,300 training observations
- 13,350 validation observations
- 13,350 test observations

Participants are split at the participant level so that data from the same participant does not appear in different splits within a single experiment.

## Prediction targets

PaceMate-AI predicts six targets:

- `flare_risk`
- `dizziness_risk`
- `fatigue_risk`
- `fainting_risk`
- `need_to_hydrate`
- `need_to_rest`

## Main findings

The repeated longitudinal ablation experiments consistently showed that the full feature set performed better than the same-day-only feature set across all six targets.

The average ROC-AUC improvement ranged from about 0.10 for `need_to_hydrate` to about 0.29 for `flare_risk`.

PR-AUC also improved for every target, and Brier scores were consistently lower when longitudinal features were included.

The repeated threshold experiments showed some variation in the validation-selected thresholds across participant splits. `need_to_rest` was particularly stable, with the same threshold selected in all five repetitions.

The results suggest that historical and longitudinal information provides useful predictive information beyond measurements from the current day alone.

## Reproducibility

The CSV files in this folder are generated by scripts in `generators/`.

The main scripts used for these analyses are:

- `tune_all_thresholds.py`
- `evaluate_all_thresholds.py`
- `repeated_threshold_f1_robustness.py`
- `ablation_longitudinal_features.py`
- `repeated_longitudinal_ablation.py`
- `create_robustness_summary.py`
- `analyze_robustness_statistics.py`

The CSV files contain the numerical results, while the Python scripts contain the code used to generate them.
